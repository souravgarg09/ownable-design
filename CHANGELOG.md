# Changelog

All notable changes to Ownable are documented here.

## 3.0.0 — 2026-09-21

Major architecture consolidation.

- reduced the core from 33 rules to 29 tighter art-direction rules and moved specialist/detail behavior into focused references;
- added explicit **new / replace / extend / refine** scope modes so polishing cannot silently become redesign;
- added a minimal-uncertainty rule: ask only when an unresolved decision materially changes truth, scope, user/task fit, or visual direction;
- added a compact **direction contract** for committed worlds: job, North Star, visual thesis, identity carriers, composition grammar, type behavior, color/material, media/proof stance, interaction thesis, responsive transformation, first viewport, anti-goals, must-preserve constraints;
- added explicit **first viewport as thesis** behavior, adapted for persuasive/experiential versus operational surfaces;
- added **prove before claim**: demonstrate product/process/evidence/mechanism when possible instead of replacing proof with prestige language;
- added **one dominant move, supporting system** to prevent every section from competing for spectacle;
- added a dedicated **media strategy** reference covering media roles, truth classes, source/edit/generate/construct/remove decisions, asset briefs, critical-asset-before-layout behavior, responsive variants, transparency, repetition, and in-context validation;
- strengthened proof-sensitive media rules so generated atmosphere cannot impersonate documentary evidence;
- strengthened image editing/background-removal guidance around real alpha and organic edge integrity;
- consolidated structure, medium, asset, motion, and responsive intervention into clearer ladders;
- kept provider-neutral capability routing and action-first execution;
- simplified standalone fallbacks so they load only for missing Taste / Impeccable / Emil domains;
- aligned Ownable more cleanly with Taste's brief/anti-default discipline, Impeccable's visual authority/direction/verification model, and Emil's motion-purpose/frequency philosophy without copying their detailed mechanics;
- deliberately rejected rigid companion defaults that would make Ownable less general, such as universal style presets, fixed aesthetic dials, mandatory dark mode, hardcoded font pools, or one-image-per-section quotas;
- added EVALS.md with behavioral tests for cliché resistance, refinement authority, asset generation/editing, proof boundaries, representation choice, first viewport quality, cross-project fingerprinting, motion restraint, portability, cultural specificity, and direction commitment;
- updated README, examples, contributing guidance, and GitHub templates to match the new architecture.

## 2.1.0 — 2026-09-21

- made Ownable explicitly provider-neutral and capability-aware across agent environments;
- added portable image generation/editing and true-alpha validation;
- added standalone fallbacks for missing specialist skills;
- strengthened companion mode, anti-default behavior, and direction commitment.

## 2.0.0 — 2026-09-21

- replaced the earlier flat rule structure with Ground → Discover → Architect → Produce → Verify;
- added global reference-universe discovery, fit-over-fashion selection, reference abstraction, hybrid coherence, action-first intervention, and conditional references.

## 1.x

Earlier releases established Ownable's original principles: subject-first art direction, Creative North Star, logo-swap testing, active image/structure/motion intervention, medium-agnostic art direction, and action-first execution.
