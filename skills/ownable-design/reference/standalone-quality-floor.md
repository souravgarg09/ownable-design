# Standalone quality floor

Load only the parts whose specialist companion is absent.

This keeps Ownable usable by itself without turning it into a duplicate of Taste, Impeccable, or Emil.

## If Taste is absent — visual craft fallback

- infer the page/surface kind, audience, vibe, and constraints before designing;
- choose typography deliberately; do not use the same default family for every project;
- use cards/containers only when they group, contain, compare, or enable interaction;
- avoid generic AI fingerprints unless the brief genuinely earns them;
- keep palette, material, shape, and icon grammar coherent;
- vary composition/rhythm because content differs, not because novelty is a quota.

Common default traps include generic mesh gradients, decorative glass, floating pill navs, same-size card rows, category-default luxury/tech palettes, monospace-as-tech costume, meaningless eyebrow labels, decorative metrics, repeated marquees, and identical reveal choreography.

## If Impeccable is absent — product/implementation fallback

- preserve scope and existing system in refine/extend work;
- keep the primary task/action obvious;
- implement working controls and relevant loading/empty/error/disabled/success states;
- preserve keyboard focus, usable contrast, touch targets, and essential semantics;
- design responsive behavior rather than merely stacking;
- render representative contexts when possible;
- inspect once, fix material defects in a batch, confirm once, then stop.

## If Emil is absent — motion fallback

- animate only when there is a clear purpose;
- reduce motion as interaction frequency rises;
- keep functional motion responsive and interruptible when possible;
- avoid identical entrance motion on every section;
- keep content visible/readable without waiting for animation;
- honor reduced-motion preferences.

## Always

A beautiful result that obscures the task, damages trust, breaks accessibility, or fails real content is not a successful Ownable result.

Report what was actually changed and verified.
