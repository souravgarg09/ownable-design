# Intervention playbook

Load this reference for active build, redesign, improvement, fix, polish, or transformation work.

The purpose is to turn art-direction judgment into changes. Do not use it to expand scope beyond the brief.

## 1. Default loop

**Understand → inspect → prioritize → execute → render/inspect again → finish**

- Understand product truth, scope, existing system, assets, content, and constraints.
- Inspect the actual experience when visual evidence is available.
- Prioritize causes, not a long issue list.
- Execute the highest-impact justified interventions.
- Re-render or re-inspect after substantial changes.
- Fix remaining high-impact art-direction defects in one bounded pass.
- Finish; do not drift into endless subjective tweaking.

When Impeccable is active, let its current refinement/redesign and bounded verification workflow own the detailed mechanics.

## 2. Structural intervention ladder

For each major section/screen/content group:

1. **Keep** when the job is clear and the structure supports it.
2. **Refine** when the job is right but hierarchy/composition is weak.
3. **Regroup/reorder** when sequence or priority is wrong.
4. **Merge** when multiple units perform the same job.
5. **Split** when one unit contains genuinely different jobs.
6. **Replace** when the concept/shell itself is wrong.
7. **Remove** when an optional unit earns no meaningful role.

Required brief/product content is protected. Reframe or relocate it rather than silently deleting it.

## 3. Asset intervention ladder

For each important visual/media asset:

1. **Keep** when it already earns the role.
2. **Reframe** through crop, scale, position, sequence, or contextual use.
3. **Transform** through truthful cleanup/editing.
4. **Replace with a stronger real asset** when reality is the better medium.
5. **Generate a new asset** when generation is truthful and conceptually better.
6. **Remove** when the experience is stronger without it.

Skip directly to the right intervention when obvious. The ladder is not bureaucracy.

## 4. Asset transformation authority

When available and justified, the agent may:
- remove backgrounds and create real alpha cutouts;
- mask and isolate subjects;
- clean clutter/distractions;
- correct color/exposure/white balance;
- relight without falsifying evidence;
- reframe or extend composition;
- correct perspective;
- remove irrelevant objects;
- replace/clean backgrounds;
- composite truthful elements;
- upscale/recover detail;
- create desktop/mobile or portrait/landscape variants.

For organic contours, prefer a real alpha matte/cutout over fake geometric masking.

## 5. Generated-media authority

When generation is the right medium, the agent may proactively create:
- photographic campaign/supporting imagery;
- watercolor or gouache;
- pencil, charcoal, ink, line drawing;
- etching/engraving;
- collage/mixed media;
- textured editorial artwork;
- diagrammatic illustrations;
- stylized 3D stills;
- material studies, textures, backgrounds;
- other subject-appropriate authored media.

Generation is not a quota. Do not create media just to fill empty space or make every section visual.

Documentary/proof and illustrative/atmospheric roles must remain distinguishable.

## 6. Sourcing from the web or connected sources

When a stronger real asset is needed and source access exists, search proactively.

Prefer:
- official/first-party sources;
- owned brand libraries;
- clearly licensed stock;
- public-domain or explicitly reusable sources;
- user-approved sources.

A search result being visible on the web is not production permission. If reuse rights are unclear, treat it as reference/inspiration or request an approved source.

Verify that the source actually depicts the intended subject before shipping it as proof.

## 7. Medium intervention

Any expressive medium can be:
**keep → refine → transform → replace → add → simplify → remove**

This applies to:
- typography;
- color/material;
- content framing;
- images/illustration;
- iconography/graphic marks;
- diagrams/data viz;
- motion/interaction;
- video/3D;
- sound;
- backgrounds/environment;
- proof presentation;
- responsive treatment.

The goal is not maximum change. Choose the least destructive intervention that solves the real problem.

## 8. Motion and interaction

Ownable decides:
- whether motion belongs;
- what element should move;
- what conceptual job it serves;
- whether it should be added, simplified, retargeted, replaced, or removed.

When Emil Kowalski skills are active, defer motion mechanics and feel to them.

Do not use the same reveal on every section. Do not preserve a technically impressive animation that weakens content, credibility, or task flow.

## 9. Responsive intervention

Do not merely stack desktop.

Possible changes include:
- different crop or source asset;
- different media type;
- simplified sequence;
- reordered proof/action;
- reduced atmospheric layers;
- different interaction model;
- focused detail instead of full scene;
- alternate signature moment.

Preserve required content/functionality and identity.

## 10. Whole-experience test

A local fix is not a win if it creates:
- perceptual repetition;
- visual imbalance;
- broken pacing;
- asset-language drift;
- inconsistent identity;
- competing focal points;
- weakened proof or task clarity.

Judge every intervention in the context of the entire experience.

## 11. Capability honesty

If a needed capability is unavailable:
- continue with every useful intervention that is possible;
- specify the blocked intervention precisely;
- do not pretend it was completed.

Do not ask the user to manually perform work that the active environment can safely do itself.
